# T-0 Recon (Tokri → dynisland)

Repo: /home/jano/src/tokri (Qt 6 Widgets, CMake, C++17). Last commit: inspect `git -C /home/jano/src/tokri rev-parse HEAD`.

## Upstream behavior
- Desktop basket: drag text, URLs, images, files.
- Shake while dragging to open basket; drop items inside.
- Drag items out to move; Ctrl/Option while dragging to copy.
- Global shortcut summons basket.
- Linux reads /dev/input/* (user in `input` group) for mouse activation; shake detection in LinuxDragShakeDetector (src/linuxdragshakedetector.cpp) polls input devices, detects BTN_LEFT drag + REL/ABS X movement, emits shakeDetected after ShakeDetector (src/shakedetector.h) completes 4 direction changes within 500ms and 20px travel.

## Key components
- tokriwindow (UI), dropawarefilesystemmodel, drophandler, textfile, filepathprovider, sortfilterproxy, thumbnailproxymodel/delegate/layout, nointernaldraglistview.
- Platform shake detectors: Linux (input evdev), Windows, macOS.
- DBus optional on Linux.

## DynIsland integration
- No plugin contract exists in dynisland (README has no plugins). T-1 must define one: a QML module under modules/plugins/<name> with manifest (id, name, icon, defaultEnabled) and registration in a PluginLoader/PluginRegistry, plus settings page entry and IPC hooks.
- Reimplement shake detection in QML/Quickshell: cannot read /dev/input directly from QML easily; options: (a) small helper binary exposing DBus signal, (b) Quickshell's built-in input monitoring if available, (c) port C++ detector to a Quickshell plugin (C++). Need verify Quickshell APIs.
- Basket UI: floating window with drop area, thumbnail grid, drag-out support. Quickshell supports drag/drop? Need verify `Drag`/`DropArea` in Qt Quick. Qt Quick has DropArea and Drag; should work.
- Global shortcut: compositor keybind (mango/niri) invoking `dynisland ipc tokri toggle` (Quickshell IPC). DynIsland already uses IPC.
