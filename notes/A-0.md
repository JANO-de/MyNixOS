# A-0 Recon (AppOutlet fork)

Repo: /home/jano/src/appoutlet-nix (upstream AppOutlet/AppOutlet, last commit bce0187). Angular 13 + Electron 19, yarn/npm, typeorm/sqlite.

## Data flow (main ↔ preload ↔ renderer)
- main.js: `BrowserWindow({ webPreferences: { nodeIntegration: true, preload: preload.js } })`; requires `./core` which loads core/interface/* and registers `ipcMain.handle` for channels in `core/interface/InterfaceChannel.js`.
- preload.js: `contextBridge.exposeInMainWorld('electronAPI', { invoke: ipcRenderer.invoke, openExternalUrl: shell.openExternal, getChildProcess: () => childProcess })`.
- renderer: Angular `CoreService.invoke(channel, ...args)` → `electronAPI.invoke` → `ipcMain.handle` → core service → repository (typeorm/sqlite or axios).
- Install path: renderer `ProcessService.installApplication(application)` switches on `application.packageType` and spawns child processes via `electronAPI.getChildProcess()`; AppImage "install" just opens `downloadUrl` in browser.
