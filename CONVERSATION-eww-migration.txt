 AGREED DESIGN (not implemented yet)
------------------------------------------------------------------------------

Self-contained folder:
    modules/desktop/shell/eww/
        eww.yuck              # island window(s), notifications, OSD, polls
        eww.scss              # styling (catppuccin, theme placeholders)
        scripts/island        # expand / collapse / init / mute controller
        scripts/osd           # volume + brightness OSD controller
        scripts/notifications.py  # DBus org.freedesktop.Notifications server
                                  # (python dbus-next) -> feeds eww via stdout

Single connector file:
    modules/desktop/shell/eww.nix     # THE only file wired to the rest of the
                                      # config; imports/reads the folder above

Design details:
  * iOS-style "island" anchored top-center.
      collapsed: day + time only (small pill)
      hover     : expands to bigger island with controls (volume slider,
                  brightness slider, mute, wifi/bluetooth toggles, battery,
                  media, systray, lock, power). Collapses on mouse leave.
  * Implemented with ONE `defwindow island` reopened with `--arg expanded=true/
    false` (window geometry cannot be changed at runtime). A small guard script
    reads an eww var `island-open` to avoid an onhover/onhoverlost feedback
    loop. Only `onhover` on the collapsed box and only `onhoverlost` on the
    expanded box (so closing one window does not trigger the other).
  * Notifications: python `dbus-next` server owning org.freedesktop.Notifications
    prints a JSON array (deflisten); eww renders popups; close via
    `busctl --user call ... CloseNotification u <id>`.
  * OSD: `osd` window fed by eww vars (osd-kind/osd-value/osd-icon); scripts
    change wpctl/brightnessctl then show + auto-hide after 1.5s.
  * Theme: eww.nix substitutes placeholders (@BG@, @SURFACE@, @TEXT@,
    @SUBTEXT@, @ACCENT@, @FONT@, @SANS@) in eww.scss from modules/theme.nix,
    and @SCRIPTS@ / @NOTIFY@ paths in eww.yuck.
  * Deploy: xdg.configFile."eww".source = <folder copied+substituted via
    pkgs.runCommand>. Wrapper bins (islandctl, osdctl, eww-notify) added to
    environment.systemPackages for niri keybinds + systemd.
  * systemd user units: eww (programs.eww.systemd.enable + ExecStartPost
    `islandctl init`), eww-notifications.
  * niri config.kdl (HOME, niri-only) keybind updates:
        remove wayle binds (Mod+W wallpaper, Mod+Comma settings,
        Mod+Ctrl+K dnd, Mod+Shift+S panel)
        wire XF86Audio{Raise,Lower}Volume / Mute -> osd volume up/down/mute
        XF86MonBrightness{Up,Down} -> osd brightness up/down
