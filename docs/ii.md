# ii (ii-p3drovfx)

Quickshell config for Hyprland on desktop/laptop. Enable: `modules.desktop.shell = "ii"; modules.desktop.ii.enable = true;`.
Package installs config tree to `$out/share/quickshell/ii`. Home-manager links to `~/.config/quickshell/ii`.
Mango/dynisland removal gated on owner acceptance (I-3b).
