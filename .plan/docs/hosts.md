# Hosts

| Host | Hardware | Compositor | Shell | Profile | Notes |
|------|----------|------------|-------|---------|-------|
| desktop | AMD + NVIDIA GTX 1060 | niri | Noctalia | full | Deskflow client, OpenRGB, data drive `/mnt/ssd`, home server, backups |
| laptop | Intel + NVIDIA RTX 3050 (PRIME offload) | niri | Noctalia | full | Deskflow server, Artcraft, stock kernel (CachyOS off) |

Build: `nh os build` (on the machine itself) or `nix build .#nixosConfigurations.<host>.config.system.build.toplevel --no-link`.

## Host-only modules

No enable switch, so the host file lists them (`parts/hosts/desktop.nix`):

`server-vikunja`, `server-ntfy`, `services-ntfy-alerts`, `theme-stylix`, `services-wol`, `server-adguard`, `programs-music-dl`, `server-music-autotag`, `services-backup`, `services-scrub`, `server-navidrome`.

The laptop gets `theme-stylix` after `commonModules`. `hosts/<host>/hardware-configuration.nix` is generated by the installer and stays outside `parts/`.
