# N-0 Recon

## Packaging pattern to reuse (from pkgs/orchard/default.nix)
- Rust via rust-overlay (`pkgs.rust-bin.stable.latest.default`); cargo deps via `pkgs.rustPlatform.importCargoLock`.
- Meson + ninja build; npmDeps via `pkgs.fetchNpmDeps`.
- qt6.wrapQtAppsHook for QML app.
- For nixscout (pure Rust + GTK4/libadwaita): use `rustPlatform.buildRustPackage` with `cargoLock.lockFile`, `meta.mainProgram`, `meta.license` (per N-12). No meson/npm needed.

## Versions (nixpkgs nixos-26.05)
- rustc: 1.95.0
- gtk4: 4.22.5
- libadwaita: 1.9.4
- sqlite: 3.51.2
- pkg-config modversions: gtk4 4.22.5, libadwaita-1 1.9.4

## rust-overlay needed?
Orchard uses rust-overlay for MSRV. nixpkgs rustc is 1.95.0. nixscout crates (gtk4-rs, libadwaita-rs, rusqlite, serde, ureq, pulldown-cmark) likely build on stable 1.95. rust-overlay not strictly needed unless a crate requires newer MSRV. Decision: try nixpkgs rustc first; add rust-overlay only if build fails (ASK owner, since it's an input).

## GTK4/libadwaita crate versions
Rust crates `gtk4` and `libadwaita` (gtk-rs) track the C library via features `v4_22`/`v1_9`. Use the feature matching system version (4.22.5 → v4_22; 1.9.4 → v1_9). Verify at build time.

## modules/home.nix (now modules/theme/gtk-qt.nix)
GTK/Qt theming pattern: catppuccin-gtk, papirus icons, inter font, kvantum. nixscout uses Adwaita symbolic icons only, no custom theming needed.

## modules/programs/orchard.nix
Pattern: `programs.<name>.enable` + `package` option, `environment.systemPackages` when enabled. nixscout follows same (`programs.nixscout.enable`).
